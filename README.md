# Rangos Preflop

App web instalable (PWA) para estudiar y consultar rangos preflop de Texas Hold'em en el teléfono.

**Abrir:** https://darwin-png.github.io/rangos-preflop/

- Tocas un asiento de la mesa y su rango se enciende en la tabla 13×13.
- **Mesa de 9:** abrir, subir sobre limpers, overlimp, 3-bet, overcall, pagar 3-bet, 4-bet/5-bet y juego de ciegas.
- **Mesa de 6:** abrir y defensa contra cada subida (3-bet / pagar), según los rangos 6-max de PokerStrategy.com (Big Stack Strategy).
- Modo **Practicar**: te reparte una mano en una situación y eliges la acción.
- Funciona sin conexión después de abrirla una vez.

## Instalar en el teléfono
- **iPhone:** Safari → Compartir → "Agregar a pantalla de inicio".
- **Android:** Chrome → menú ⋮ → "Instalar app".

## Actualizar
Editar `index.html` y subir el número de versión en `sw.js` (`rangos-vN`) para que los teléfonos tomen la versión nueva.
